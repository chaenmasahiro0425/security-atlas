# トップページの3方向比較

1. Atlas: 最初の日本地図と大きな見出しを復元。全国の事例、直近の公表、原因の透明性を重ねる。既存のブランドとの連続性が最も高い。
2. Newsroom: 日付と企業ロゴの速報一覧をファーストビューの中心にする。密度は高いが初めての人が目的を理解しにくい。
3. Research commons: みんなの情報提供と点検プロンプトを主役にする。参加の意図は強いが、事件の広がりが見えにくい。

採用: Atlasを主役とし、Newsroomの新着リストとResearch commonsの参加導線を統合。

色: 白 #FFFFFF、本文 #142846、青 #2457EB、淡青 #EEF3FF、罫線 #DDE5F2、注意 #AD682C。
文字: Noto Sans JPで日本語、Interで英字と数字。本文14px、DB12px、見出し56px、モバイル34px。
構成: ヘッダー → 地図と理念 → 収録数/月別公表数 → 最新事件 → 今のDB → 学び/プロンプト → 投稿/MCP。
地図は全国の事件を扱うイメージ。地理的な発生位置を偽装しない。統計は収録事例のみで動的に計算する。

検証: desktop/mobile screenshots、長い日本語企業名、横スクロールのDB、キーボード、reduced motion、欠損ロゴ、検索と詳細リンクを確認。
