# Security Atlas

日本の不正アクセス・情報漏えいを、企業の一次発表から読む検索データベース。初心者向けの説明と技術的な詳細を切り替えられます。

2026年10月3日確認の初期11事例を収録しています。日本国内の事件を網羅したものではありません。公表日・発生日・判明日を分け、原因の公開状況と漏えいの確認状況を明示します。未知の侵入経路を推測で補完しません。

## ローカル起動

Node.js 22以上を推奨。

```sh
npm ci
npm run dev
```

http://127.0.0.1:3182 で表示。URLの検索条件と事例IDを共有できます。

## 検証

```sh
npm test
npm run build
npx playwright install chromium
npx playwright test tests/ui.spec.ts --workers=1
```

UIテストには開発サーバーの起動が必要です。検索、フィルター、詳細、URL復元、JSON取得、スマホの横幅を確認します。

## データと更新

データは `public/data/incidents.json`。サーバーや個人情報の収集は不要です。検索はブラウザ内で実行します。静的ホスティングに対応します。

1. 公式発表を読み、初報と続報の日時・人数・対象を照合します。
2. 参考ブログは発見に利用し、転載せず、各事例には公式発表へのリンクを保存します。
3. 原因は「公表」「一部公表」「未公表」、影響は「漏えい確認」「漏えいの可能性」を区別します。件数を人数に置き換えず、対象集団を安易に足しません。
4. 同一事件の続報は timeline と sources に追加します。別攻撃は別IDにします。公開済みレコードの変更はPRでレビューします。
5. verifiedAt を確認日で更新し、テスト・build・実画面を確認します。

自動収集・自動更新は未実装です。掲載内容は各確認日時点の情報で、続報により変わることがあります。原因説明は企業の公開説明を要約したもので、独立したフォレンジック調査ではありません。

## 公開

公開環境・独自ドメインは未確定です。GitHub Pagesのサブパスでbuildする場合は `BASE_PATH=/リポジトリ名/ npm run build` を指定します。独自ドメインまたはルート配信は通常のbuildを使用します。配信対象はdistです。

Google Fontsは外部配信です。フォントが取得できない場合はシステムフォントで表示します。アクセス解析・Cookie・ログインはありません。
